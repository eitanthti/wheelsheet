# WheelSheet

A weekly, filter-driven watchlist for cash-secured-put sellers. Twenty-five US names ranked by 30-day put premium yield, with IV rank and percentile over a real 252-day IV history, HV30 and the vol-risk premium, expected move, days to earnings, chain liquidity, and a two-year held-above-strike rate.

Site: https://eitanthti.github.io/wheelsheet/ · Latest issue: https://eitanthti.github.io/wheelsheet/watchlist/

Every figure is derived; nothing is a recommendation. See the [disclaimer](https://eitanthti.github.io/wheelsheet/disclaimer.html).

**Join the waitlist:** open a [waitlist issue](https://github.com/eitanthti/wheelsheet/issues/new?template=waitlist.yml), or Watch → Custom → Issues to be notified of each new issue.

Publishing contract for issues: [`watchlist/README.md`](watchlist/README.md).
